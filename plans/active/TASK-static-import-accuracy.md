# Python 导入与架构检查准确性

- 类型：Bugfix；风险：high；涉及 SPEC-001、MOD-002、MOD-003、MOD-006。授权来自持续实现任务，不构成设计批准。
- 范围：Python 导入事实、图构建、架构规则及其测试/设计。本轮保留其他工作树内容。
- 根因：图构建把相对导入直接去掉前导点，并用首个前缀匹配猜目标；`from package import module` 未建立子模块边。架构检查将动态盲区视为全局通过，规则缺字段则空字符串匹配所有节点。
- 修复：按纳管包根和 Python 相对导入层级确定绝对模块；命中子模块分别建边，无法确定的内部或相对导入生成未知诊断；同一模块名映射多个文件时不猜测。保留不同来源的边；静态盲区使必需架构结论为 unknown 并阻断。禁止依赖规则的端点必须为非空字符串，缺陷是配置故障。
- 验收：真实包内相对导入、`from ... import ...`、多代码根歧义、动态导入及内部解析缺失；静态循环、禁止依赖和缺陷规则分别有正反例；打乱输入得到相同内容。
- 限制：静态分析无法涵盖运行时注入或所有动态依赖；快照多文件发布和模块归属聚合另行处理。
