# ChangeSet 基线与范围比较

- 类型：Feature；风险：high；涉及 SPEC-001、MOD-001、MOD-007、MOD-008。用户授权持续实现模块，不表示审批已发生。
- 写入范围：ChangeSet 契约和设计、CLI、治理模块、相关测试与本任务记录；保留其他既有改动。
- 设计：登记时以仓库相对路径和内容 SHA-256 对整个仓库取基线，权威基线记录保存在 `engineering/changesets/<ID>.baseline.json`，其摘要同时覆盖路径清单和 ChangeSet 声明，并绑定 ChangeSet 的 `baseline_manifest`。排除 Git 内部、虚拟环境、缓存、派生索引、报告及 Evidence 审计目录，以及本次 ChangeSet 的两个记录本身；这些排除项是范围检查盲区，不能声称文件系统隔离。链接不跟随目录；符号链接目标越界或目录链接均拒绝登记/比较，文件链接的目标和内容均进入摘要。登记前后两次采样一致才发布，冲突不能覆盖已有记录。
- 比较：读取并校验基线结构及摘要，再对当前快照按路径集合计算新增、修改、删除；移动表现为旧路径删除和新路径新增，两者均检查。受保护范围优先于写入范围。全仓库内容比较能覆盖已提交、未提交和未跟踪变更；采样故障、基线丢失或篡改阻断。
- 验收：真实临时仓库新增/修改/删除/重命名、提交后比较、路径含空格和越界链接；基线篡改及重复登记不能通过或覆盖；受保护路径优先；已有门禁测试回归。
- 限制：扫描并非操作系统层锁，比较后并发写入无法阻止；需宿主或 CI 在可信隔离环境强制执行。敏感内容只记录摘要和路径，不存文件内容。
